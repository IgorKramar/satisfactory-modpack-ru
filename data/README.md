# Данные перевода

JSON хранится в детерминированном gzip, чтобы не раздувать историю. `python tools/catalog.py unpack` создаёт обычный JSON в `build/data/`.

- `translations.json.gz`: полный редакционный каталог, включая варианты конфликтующих ключей. Поле `deployed` относится к локальному пакету на 4 октября 2026, а не к установке из этого репозитория.
- `editorial.json.gz`: 8 286 уникальных исходных строк и их редакционная память.
- `planner.json.gz`: 820 записей / 798 уникальных английских источников для Planner 1.7.1; ещё не установлены в игре.
- `mods.lock.json`: версии, публичные ссылки загрузок и контрольные суммы архивов модов; сами моды не включены.
- `boombox-messages.json`: подготовленные переводы строк FString; не скомпилированный мод.

Оригинальные названия, тексты и идентификаторы остаются материалами соответствующих авторов. MIT относится к собственному коду проекта, а не к сторонним текстам.
