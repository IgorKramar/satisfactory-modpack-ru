# Как помочь

Для сообщения об ошибке укажите версию игры, версию мода, язык, точный экран и исходную строку. Приложите снимок без личных данных; не загружайте сохранение целиком, если для воспроизведения достаточно текста.

1. Распакуйте каталоги: `python tools/catalog.py unpack`.
2. Найдите запись по `mod`, `namespace`, `key`, `source`.
3. Редактируйте исходный каталог в `build/data/`, затем упакуйте его детерминированным gzip: `python tools/catalog.py pack`.
4. Выполните `python tools/catalog.py check` и `python tools/catalog.py build-locres`.
5. Объясните контекст и причину правки. Отметьте, была ли проверка в игре.

Термины согласуются с основной игрой: Первопроходец, ХАБ, ММА, энергослизень, энергомодуль, Соммерслуп. Сохраняйте числа, плейсхолдеры, форматные спецификаторы, теги и технические идентификаторы. Предпочитайте ясный русский текст буквальному копированию порядка английских слов.

Для изменений C++ сначала запускаются отдельные тесты. Проверку Unreal и игры нельзя заменять результатом этих тестов. Не отключайте защиту по хешу, чтобы заставить модуль работать с другой версией DLL.

Вклад с помощью ИИ допустим с указанием этого факта; машинный черновик требует редакторской проверки.
